# 💻 04 — Developer

Tài liệu dành cho **Developer** tại Cyberk. Mọi quy trình, cẩm nang và hướng dẫn dưới đây được viết cho người trực tiếp viết code.

---

## Thứ tự đọc — theo hành trình dự án

```
1. dev-new-repo       ← Tạo repository đúng chuẩn (ai cũng đọc được)
        ↓
2. dev-bootstrap      ← Bootstrap nền tảng: ERD, auth, admin, API (CTO viết, team đọc)
        ↓
3. dev-daily          ← Làm việc hàng ngày: board, task, daily meeting
        ↓
4. dev-write-brd      ← Khi phát sinh yêu cầu mới → tự document
        ↓
5. dev-tasks-logs     ← Tạo task từ PRD/BRD lên board bằng AI
```

> **Ghi chú:** [dev-project-onboarding/](./dev-project-onboarding/) và [dev-daily-report/](./dev-daily-report/) đọc song song từ bước 3 trở đi.
