# 🆕 Tạo Repository Mới

> **Đối tượng:** Developer được giao tạo repo cho dự án mới
> **Mục đích:** Chuẩn hóa cách tạo repository Cyberk — từ đặt tên, cấu hình GitHub, đến setup local

## Tài liệu

| File | Nội dung | Đọc khi |
|------|----------|---------|
| [dev-new-repo-process.md](./dev-new-repo-process.md) | Các bước cụ thể, checklist, vai trò | Cần làm theo từng bước |
| [dev-new-repo-handbook.md](./dev-new-repo-handbook.md) | Cách nghĩ đúng — tại sao mỗi bước lại quan trọng, ví dụ tốt/tồi | Muốn hiểu sâu, tránh sai lầm phổ biến |

## Đọc theo thứ tự

1. **Lần đầu** → đọc handbook để hiểu tại sao
2. **Khi làm thật** → mở process tab bên cạnh làm từng bước
3. **Cần mẫu** → mở example, copy-paste
