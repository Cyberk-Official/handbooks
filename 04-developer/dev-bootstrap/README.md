# 🚀 Bootstrap Dự Án

> **Đối tượng:** CTO (điều phối) + Tech Lead (thực thi)
> **Mục đích:** Chuẩn hóa giai đoạn khởi động dự án — từ sau khi ký hợp đồng đến trước Sprint 1

Bootstrap Phase xảy ra sau [Internal Planning](../../05-product-owner/po-planning/) và trước [Kick-off với client](../../05-product-owner/po-kick-off/). Mục tiêu: đến ngày Sprint 1, team có 50–80% infrastructure sẵn sàng.

## Timeline tổng thể

```
Ký hợp đồng
    → Internal Planning (½ ngày)
    → Bootstrap Phase (3–5 ngày) ← Bạn đang ở đây
    → Kick-off với client
    → Sprint 1 (business logic)
```
