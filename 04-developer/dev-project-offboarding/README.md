# Project Offboarding — Bàn giao khi Developer rời dự án

> **Đối tượng:** Developer chuẩn bị rời dự án hoặc chuyển sang dự án khác.
> **Mục đích:** Người tiếp nhận tiếp tục được công việc từ code, board và tài liệu đã bàn giao, không phải đoán hoặc chờ hỏi lại người cũ.

## Tài liệu

| File | Loại | Đọc khi |
|------|------|---------|
| [dev-project-offboarding-process.md](./dev-project-offboarding-process.md) | Process | Cần biết các bước, đầu ra, người xác nhận và checklist trước khi rời dự án |
| [dev-project-offboarding-handbook.md](./dev-project-offboarding-handbook.md) | Handbook | Cần cách đóng gói task dở, viết tài liệu, demo và bàn giao quyền; có ví dụ tốt/tồi |

## Đọc theo thứ tự

1. Đọc **handbook** để hiểu thế nào là bàn giao dùng được.
2. Mở **process**, đối chiếu từng bước với lịch bàn giao PO đã xác nhận.
3. Cập nhật bằng chứng vào hồ sơ bàn giao trước khi gửi link qua Telegram.
