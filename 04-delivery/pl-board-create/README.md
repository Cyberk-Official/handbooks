# Khởi tạo Board dự án — Cẩm nang cho PM / Tech Lead

> Folder này dành cho **PM / Tech Lead** — hướng dẫn cách khởi tạo và cấu hình GitHub Projects Board chuẩn cho mỗi dự án tại Cyberk.
> Board là nơi bắt đầu mọi dự án — chưa có board chuẩn thì chưa bắt đầu.

## Mục lục

| File | Loại | Mô tả |
|------|------|-------|
| [board-create-process.md](./board-create-process.md) | Process | Quy trình: chuẩn bị input → AI tạo board → thiết lập views → verify |

## Audience

- **Đọc folder này:** PM, Tech Lead (người khởi tạo board cho dự án mới)
- **Sử dụng board:** Toàn bộ team dự án (Dev, QA, Designer)
