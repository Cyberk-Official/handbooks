# Tài liệu gửi khách trước Kick-off

> Folder này chứa các tài liệu **PO gửi cho khách trước buổi Kick-off** và **trình bày trong buổi Kick-off đầu tiên**, để khách hiểu Cyberk sẽ làm gì trong 30 ngày đầu.
> Quy trình gửi và trình bày: xem [`po-kick-off/kick-off-process.md`](../po-kick-off/kick-off-process.md)

## Mục lục

| File | Loại | Mô tả |
|------|------|-------|
| [cyberk-zero-to-product-en.pdf](./cyberk-zero-to-product-en.pdf) | Bản gửi khách (EN, PDF) | Xuất từ file HTML bên dưới. Gửi file này cho khách |
| [cyberk-zero-to-product-en.html](./cyberk-zero-to-product-en.html) | Bản gốc (EN, HTML) | Quy trình Zero to Product 30 ngày, 11 trang A4: Understand → Build → Launch → Care, timeline, nhịp làm việc, team, cách xử lý thay đổi, khách cần chuẩn bị gì |

## Cách dùng

- **Gửi cho khách:** gửi file PDF. Mỗi lần sửa file HTML, xuất lại PDF: mở HTML bằng trình duyệt → Print → Save as PDF (khổ A4, margin None, bật Background graphics).
- **Trình bày trong Kick-off:** share màn hình file HTML hoặc PDF ở phần *Approach & Strategy* của buổi call.
- **Sửa nội dung:** sửa trực tiếp file HTML. Style đồng bộ với [tài liệu quy trình thiết kế](../../11-design/client-documents/cyberk-design-process-en.html), không đổi font, màu hay bố cục.

## Audience

- **Đọc folder này:** Product Owner
- **Người nhận tài liệu:** khách hàng dự án Zero to Product
