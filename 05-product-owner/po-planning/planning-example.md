# Planning — Mẫu tin nhắn gửi board cho khách

**Người chịu trách nhiệm:** PO dự án
**Cập nhật lần cuối:** 2026-11-26

> Gửi **ngay sau** khi cả team cam kết EOD, trong group `[Project] - Cyberk devs`. Không gửi file trơn — phải kèm summary. Cách nghĩ: xem [Cẩm nang Planning](./planning-handbook.md).

---

## Mẫu chưa tốt

```
Hi [Client Name], please find the attached project board.
```

Khách mở PDF, lướt qua, đóng lại. Không nắm ý chính, không biết phần nào quan trọng.

## Mẫu tốt

```
Hi [Client Name],

Our internal planning session is complete. 
Please find attached the project board for [Project Name]
(PDF — you also have view access to the live board).

Here's a quick summary:

📋 Approach
- [1–2 câu mô tả cách team sẽ tiếp cận dự án]
- Example: "We'll follow an agile approach with 1-week sprints, 
  starting with the core user flow before building out secondary features."

⚠️ Key Risks
- [Risk 1]: [Mitigation plan]
- [Risk 2]: [Mitigation plan]
- Example: "Third-party API documentation is incomplete — 
  we've allocated a spike in Sprint 1 to validate integration."

🎯 Strategy
- [1–2 câu về chiến lược delivery]
- Example: "We prioritize the Key Success Features for the first 
  3 sprints to ensure the core value is deliverable on time."

We'll walk you through the plan in detail during our kick-off call.

Best,
[PO Name]
```
