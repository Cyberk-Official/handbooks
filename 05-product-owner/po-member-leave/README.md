# 🚪 Member Leave — Thành viên Rời Dự Án

> **Đối tượng:** Product Owner, Thành viên rời đi
> **Mục đích:** Rời dự án thật đơn giản trong 4 bước `THANK-YOU → HANDOVER → REMOVE → AGREEMENT`: cảm ơn khách và team, để lại file kinh nghiệm bảo trì, gỡ quyền truy cập, ký cam kết hoàn tất.
